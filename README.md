# Avito SERP Analyzer

Анализ поисковой выдачи Avito из Excel-файла: кластеры спроса, свежесть, конкуренты, незакрытые сценарии, карта спроса и гипотезы. Метрики и бакеты считает код, аналитику пишет LLM (OpenAI-совместимый API). Результат — Markdown-отчёт (секции 1–10) со скачиванием.

**Stateless**: история не сохраняется, БД нет, каждый запуск — новый анализ.

## Как это работает

1. **Парсинг Excel** — fuzzy-маппинг ядерных колонок (`Заголовок`, `Цена`, `Дата публикации`, `Просмотров всего`, `Платные услуги`, продавец, `категория 1–6` и т.д.). Товарные колонки ниши (`Высота`, `Материал`…) игнорируются с предупреждением. Нет ядерной колонки — значения `[НЕТ ДАННЫХ]`, анализ не ломается.
2. **Метрики (код)** — возраст объявления, бакеты свежести `0–1 / 2–3 / 4–7 / 8–30 / 31+`, грубый `просмотры/день`, промо-флаги, агрегаты продавцов, сводные таблицы.
3. **Стадия A (LLM, JSON, temperature=0)** — каждому объявления: теги кластеров (товарный / характеристический / сценарный / проблемный / коммерческий), B2C/B2B, поисковые запросы, УТП, сценарий. Retry 1× при невалидном JSON; при фолбэке карта спроса заполняется `[НЕТ ДАННЫХ]`.
4. **Карта спроса (код)** — точные счётчики «кластеры × бакеты»: числа от LLM не зависят.
5. **Стадия B (LLM)** — финальный Markdown-отчёт секций 1–10 (включая 5–15 гипотез и вывод из 7 пунктов), карта спроса подставляется в секцию 8 из кода.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # впишите ROUTERAI_API_KEY

streamlit run app.py
```

Откроется http://localhost:8501. Загрузите `.xlsx`, укажите нишу и регион, нажмите «Анализ».

### Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `ROUTERAI_API_KEY` | API-ключ (обязательна) | — |
| `ROUTERAI_BASE_URL` | Базовый URL API | `https://routerai.ru/api/v1` |
| `LLM_MODEL` | Модель | `openai/gpt-4o-mini` |
| `LLM_TIMEOUT` | Таймаут запроса, сек | `180` |

Ключ читается только из env, в отчёт и логи не попадает.

## Тесты

```bash
python -m pytest tests/
```

Покрытие: парсер дат (в т.ч. переход года), маппинг колонок, бакеты свежести, сборка отчёта с секциями 1–10 и картой спроса из кода. Фикстура `tests/fixtures/sample.xlsx` — синтетическая выгрузка по колонкам реального файла.

## Docker

```bash
docker build -t avito-analyzer .
docker run -p 8501:8501 -e ROUTERAI_API_KEY=sk-... avito-analyzer
```

Приложение слушает `0.0.0.0:8501`, healthcheck — `/_stcore/health`.

## Деплой в Coolify

1. Запушьте репозиторий в Git (приватный remote; добавьте deploy key Coolify).
2. В Coolify: **New Resource → GitHub/GitLab** → выберите репозиторий → **Build Pack: Dockerfile**.
3. Порт: **8501**.
4. Env-переменные в UI Coolify:
   - `ROUTERAI_API_KEY`
   - `ROUTERAI_BASE_URL=https://routerai.ru/api/v1`
   - `LLM_MODEL=openai/gpt-4o-mini`
5. Домен и HTTPS — средствами Coolify (Traefik). Проверьте healthcheck `/_stcore/health`.

### ⚠️ Безопасность

Приложение **без авторизации**: открытый URL позволит любому запускать анализ и жечь кредиты RouterAI. Рекомендации:

- не индексируйте домен (`X-Robots-Tag`, robots.txt) и не публикуйте ссылку;
- закройте доступ basic-auth / SSO на уровне прокси Traefik или домена в Coolify;
- не используйте ключ с большими лимитами.

## Вне объёма

История/БД, Supabase, n8n, авторизация, Word/PDF, пакетная обработка, сравнение регионов, парсинг Avito (только готовый Excel).
